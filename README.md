# Community dictionary

A git-based community dictionary of Taiwanese words: accent variation (腔口差), new words (台語新詞), missing words, and more. Contributors sign in with GitHub and submit one form; each submission becomes a pull request for review.

Status and plan: [`docs/roadmap.md`](docs/roadmap.md). The entry schema and checks are built; the submission Worker and the site are not yet.

Each entry is one JSON file at `entries/<login>/<key>.json`.

Contributed data is released under CC0 1.0.
