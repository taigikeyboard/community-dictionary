# Community dictionary

A community dictionary of Taiwanese words: accent variation (腔口差), new words (台語新詞), and words other dictionaries lack. Contributors sign in with GitHub and fill in one form; each submission becomes a pull request that the maintainer reviews, and collected words are imported into TaigiKeyboard.

<https://taigikeyboard.tw/community-dictionary/>
